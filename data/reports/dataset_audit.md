### Clinical Imbalance & Metric Guidance
- **Cath (Overall CAD)** exhibits moderate class imbalance (71.3% positive vs 28.7% negative). A baseline dummy classifier predicting 'CAD' for all patients would achieve 71.3% accuracy without learning any clinical patterns. **Accuracy alone is strictly insufficient.** Model evaluation MUST emphasize PR-AUC, ROC-AUC, Recall, Precision, and F1-score.
- **LAD Stenosis** is balanced (58.4% Stenotic vs 41.6% Normal). LAD supplies ~50% of the left ventricular myocardium.
- **LCX Stenosis** (39.3% Stenotic) and **RCA Stenosis** (37.6% Stenotic) have minority positive classes (~1.6:1 negative-to-positive ratio). Models must prioritize positive class recall to prevent missed coronary artery stenosis in critical branches.

### Target Co-occurrence & Diagnostic Coherence
Cath represents overall CAD confirmed by catheterization. In coronary catheterization practice, CAD is typically confirmed if at least one major epicardial coronary artery has ≥50% stenosis.
- In **302 of 303 patients (99.67%)**, `Cath == 'CAD'` is exactly equivalent to `(LAD == 'Stenotic' | LCX == 'Stenotic' | RCA == 'Stenotic')`.
- **Observed Anomaly at Row Index 93**: Patient has `LAD=Stenotic`, `LCX=Normal`, `RCA=Normal`, but `Cath=Normal`. This may reflect either a recording typo or a borderline lesion evaluated differently by the reading cardiologist. To maintain dataset integrity, this raw data point is preserved without alteration and documented here.

## 4. Leakage Audit

To ensure medical validity and prevent target leakage:

1. **Mandatory Excluded Columns**: The four targets `Cath`, `LAD`, `LCX`, and `RCA` **MUST NEVER enter feature matrix X**.
2. **Investigation of Potential Leakage Features**:

### Feature: `Region RWMA`
- **Why Suspicious**: Echocardiographic Regional Wall Motion Abnormality score/count. RWMA is clinically linked to coronary artery distribution territories and has high correlation with LAD (r=0.36) and Cath (r=0.32).
- **Clinical Evidence**: Wall motion abnormalities manifest when myocardial perfusion is compromised. However, RWMA is obtained via transthoracic echocardiography (TTE) prior to catheterization, not from angiographic dye or catheter intervention. Dataset documentation lists echocardiographic features as allowable inputs.
- **Recommended Action**: Retain in feature pool ('Use available: Echocardiographic features'), but strictly enforce the rule: RWMA must NOT be interpreted as 3D lesion coordinates. Include sensitivity ablation in model evaluation (performance with vs without RWMA).

### Feature: `Exertional CP`
- **Why Suspicious**: Zero-variance feature (constant across 100% of samples).
- **Clinical Evidence**: All 303 rows contain 'N'. Provides zero discriminatory information.
- **Recommended Action**: Exclude from model training feature matrix X during preprocessing pipeline.

### Feature: `BMI vs (Weight, Length)`
- **Why Suspicious**: Mathematical collinearity (deterministic formula: BMI = Weight / (Length / 100)^2).
- **Clinical Evidence**: High collinearity between BMI, Weight, and Length in linear modeling.
- **Recommended Action**: Not target leakage, but feature collinearity. Retain for tree-based models (XGBoost/RandomForest) which naturally handle collinearity, or evaluate dropping redundant terms for linear baselines.

### Feature: `CHF`
- **Why Suspicious**: Severe category sparsity (only 1 positive case out of 303 rows).
- **Clinical Evidence**: 302 'N' vs 1 'Y' (99.67% constant). High risk of spurious feature importance or split instability.
- **Recommended Action**: Retain in feature schema for patient simulator input compatibility, but apply tree regularizers or evaluate low-variance feature filter to prevent split overfitting on a single record.

## 7. Preprocessing Strategy Proposal (For Stage 2)

All transformations that learn statistical parameters will be encapsulated strictly inside the scikit-learn cross-validation folds:

1. **Target Separation**: Extract `Cath`, `LAD`, `LCX`, `RCA` into target vectors $y_{Cath}, y_{LAD}, y_{LCX}, y_{RCA}$. Exclude from feature matrix $X$.
2. **Zero-Variance Filtering**: Drop `Exertional CP` (all 303 rows are 'N').
3. **Categorical Normalization & Encoding**:
   - Fix typo: `Sex == 'Fmale'` → `Female`, binary encode Male=1, Female=0.
   - Standardize binary 'Y'/'N' features → 1 / 0.
   - Ordinal mapping for `VHD` ('N': 0, 'mild': 1, 'Moderate': 2, 'Severe': 3).
   - One-hot encoding for nominal multi-class ECG variable `BBB` ('N', 'LBBB', 'RBBB').
4. **Numerical Preprocessing**:
   - Missing value safety net: `SimpleImputer(strategy='median')` (0 missing currently, but vital for simulator robustness).
   - Robust scaling: `RobustScaler` or `StandardScaler` for distance/linear models; XGBoost/Tree models remain unaffected by monotonic scaling.
5. **Class Imbalance Handling**:
   - Use algorithm-level weighting (`scale_pos_weight` in XGBoost, `class_weight='balanced'` in logistic/tree models).
   - Avoid global oversampling (SMOTE) outside validation folds to prevent data leakage.
6. **Feature Selection**:
   - Evaluate feature importance via L1 penalty and tree-based mutual information.
   - Run ablation with and without `Region RWMA` to quantify dependency.

## 8. Validation Strategy Proposal (For Stage 2)

Given the sample size ($N = 303$):
1. **No Single Train/Test Split**: A single random 80/20 train/test split on 303 rows leaves only ~60 test samples, creating unacceptably wide confidence intervals.
2. **Repeated Stratified K-Fold Cross-Validation**: Use **5-Fold Stratified CV with 5 Repeats (25 evaluation runs)** for each of the 4 targets independently.
3. **Multi-Target Modeling Architecture**:
   - Model 1: `Cath` (Overall CAD status)
   - Model 2: `LAD` (LAD stenosis probability)
   - Model 3: `LCX` (LCX stenosis probability)
   - Model 4: `RCA` (RCA stenosis probability)
4. **Metric Suite**: Accuracy, Precision, Recall, F1-Score, ROC-AUC, and PR-AUC (Average Precision).
5. **Probability Calibration**: Brier Score and calibration curves (Isotonic/Platt calibration) because probabilities directly feed the 3D heart risk visualization.
