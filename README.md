# CoroVista

> **Multimodal AI Hackathon 2026 — Track A: Cardiovascular Risk Visualization & Prediction**  
> **Clinical Safety Disclaimer**: Predictions generated by CoroVista are for decision-support and educational purposes only. They are not a substitute for formal diagnostic coronary angiography or professional clinical imaging.

---

## 1. Project Objective

CoroVista is an intelligent, web-based cardiovascular decision-support system designed to:
1. Predict overall **Coronary Artery Disease (CAD)** diagnosis (`Cath`).
2. Predict vessel-specific stenosis probabilities for the three primary coronary arteries:
   - **LAD** — Left Anterior Descending Artery
   - **LCX** — Left Circumflex Artery
   - **RCA** — Right Coronary Artery
3. Dynamically visualize predicted vessel-specific stenosis probabilities on an interactive 3D anatomical coronary model.
4. Provide interpretable explanations using **SHAP** feature attribution.
5. Offer an interactive **Patient Simulator** enabling clinicians to simulate physiological scenarios and immediately observe updated stenosis risks.

---

## 2. Track A Requirements & Medical Interpretation

### Predictive Modeling Scope
- Predict Overall CAD (`Cath`), `LAD` stenosis, `LCX` stenosis, and `RCA` stenosis from pre-catheterization clinical data.
- Feature categories allowed: Demographic, Clinical Examination/History, ECG, Laboratory, and Echocardiographic features.
- **Strict Leakage Prevention**: Ground-truth target columns (`Cath`, `LAD`, `LCX`, `RCA`) **must never enter the feature matrix $X$**.
- Evaluation standard: Accuracy, Precision, Recall, F1-Score, and ROC-AUC / PR-AUC.

### Anatomical & 3D Visualization Scope
- Render an interactive 3D heart/coronary artery model using Three.js / React Three Fiber.
- **Critical Medical Boundary**: The dataset does **not** contain 3D spatial lesion coordinates or voxel segmentations. Therefore, CoroVista visualizes **vessel-level stenosis probabilities** on LAD, LCX, and RCA anatomical branches. Regional Wall Motion Abnormalities (RWMA) must not be misrepresented as physical lesion coordinates.

## 4. Dataset Information & Audit Findings

The primary dataset source is `data/raw/extention of Z-Alizadeh sani dataset.xlsx` (an extension of the Z-Alizadeh Sani cardiology dataset).

### Workbook Architecture
- **Total Sheets**: 2 (`'Sheet 1 - Table 1'`, `'Sheet1'`)
- **Primary Data Sheet**: `'Sheet 1 - Table 1'` (303 patient records, 59 columns)
- **Secondary Sheet**: `'Sheet1'` (100 column headers representing an extended medication template, 0 patient data records)
- **Raw Data Preservation**: The original Excel workbook is strictly preserved under `data/raw/` and is never modified in place.

### Key Audit Findings
1. **Missing Data**: **0 missing values (0.00%)** across all 59 columns in `Sheet 1 - Table 1`.
2. **Duplicate Records**: **0 duplicate patient records**.
3. **Targets Breakdown ($N = 303$)**:
   - **Cath (Overall CAD)**: Positive (`CAD`) = 216 (71.29%), Negative (`Normal`) = 87 (28.71%), Imbalance ratio: **2.48:1**.
   - **LAD Stenosis**: Positive (`Stenotic`) = 177 (58.42%), Negative (`Normal`) = 126 (41.58%), Imbalance ratio: **1.40:1**.
   - **LCX Stenosis**: Positive (`Stenotic`) = 119 (39.27%), Negative (`Normal`) = 184 (60.73%), Imbalance ratio: **1.55:1**.
   - **RCA Stenosis**: Positive (`Stenotic`) = 114 (37.62%), Negative (`Normal`) = 189 (62.38%), Imbalance ratio: **1.66:1**.
4. **Data Discrepancy (Row 93)**:
   - In 302 of 303 cases (99.67%), `Cath == 'CAD'` is equivalent to having at least one stenotic vessel (`LAD | LCX | RCA == 'Stenotic'`).
   - At row index 93: Patient has `LAD='Stenotic'`, `LCX='Normal'`, `RCA='Normal'`, yet `Cath='Normal'`. This anomaly is documented without modification.
5. **Zero-Variance Feature**:
   - `Exertional CP`: Value is `'N'` for 100% of samples (303/303). Excluded from model feature matrix $X$ during preprocessing.
6. **Categorical Irregularities**:
   - `Sex`: Contains label typo `'Fmale'` (127 samples) alongside `'Male'` (176 samples). Propose mapping `'Fmale'` → `'Female'`.
   - `VHD`: Inconsistent casing (`'mild'`, `'Severe'`, `'Moderate'`, `'N'`). Standardize and map to ordinal levels.
7. **Near-Constant Features**:
   - `CHF`: Only 1 positive patient (`'Y'`), 302 negative (`'N'`) (99.67% dominant).
   - `LowTH Ang`: Only 2 positive patients (`'Y'`) (99.34% dominant).
8. **Physiological Outliers**:
   - Extreme values detected in `TG` (max 1050 mg/dL), `FBS` (max 400 mg/dL), `PLT` (max 742, min 25), and `EF-TTE` (min 15%). All values represent valid, physiologically severe cardiovascular states and are retained.

## 7. Stage 2 Machine Learning Benchmark Results

Evaluated across **5-Fold Stratified CV with 5 Repeats (25 evaluation runs)**:

| Target | Clinical Endpoint | Selected Best Model | Preprocessing | Calibration | ROC-AUC (Mean ± Std) | PR-AUC (Mean ± Std) | Balanced Accuracy | Brier Score |
|---|---|---|---|---|---|---|---|---|
| **Cath** | Overall CAD Status | **XGBoost** | One-Hot / None | Sigmoid (Platt) | **0.910 ± 0.041** | **0.958 ± 0.021** | 0.843 ± 0.056 | **0.108** |
| **LAD** | Left Anterior Descending | **XGBoost** | One-Hot / None | Sigmoid (Platt) | **0.836 ± 0.049** | **0.878 ± 0.041** | 0.763 ± 0.056 | **0.165** |
| **LCX** | Left Circumflex | **RandomForest** | One-Hot / None | Uncalibrated | **0.724 ± 0.065** | **0.608 ± 0.086** | 0.662 ± 0.060 | **0.210** |
| **RCA** | Right Coronary Artery | **LogisticRegression** | One-Hot / Standard | Uncalibrated | **0.716 ± 0.060** | **0.613 ± 0.075** | 0.666 ± 0.048 | **0.225** |

### Key Stage 2 Insights:
1. **Model Diversity**: As expected from coronary anatomy and vascular territories, independent algorithms perform best for different targets (XGBoost for main CAD and LAD; Random Forest for LCX; regularized Logistic Regression for RCA).
2. **Ablation Findings**:
   - `Region RWMA` provides consistent additive value for LAD ($+0.021$) and Cath ($+0.010$). Without RWMA, models still achieve ROC-AUC $> 0.80$, proving the model is not brittle.
   - `BMI` collinearity does not harm tree models ($\Delta < 0.004$); BMI is retained for simulator compatibility.
3. **Probability Calibration**: Sigmoid Platt calibration significantly reduces Brier score and Expected Calibration Error (ECE) for CAD and LAD, ensuring that probabilities driving the 3D heart risk visualization are reliable.
