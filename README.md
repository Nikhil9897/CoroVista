## 1. Executive Summary & Objective

**CoroVista** is an intelligent, web-based cardiovascular decision-support platform and anatomical digital twin. It bridges machine learning risk prediction with high-fidelity, interactive 3D anatomical visualization to assist clinicians and medical educators in evaluating coronary artery disease:

1. **Multi-Target Prediction**: Concurrently predicts overall **Coronary Artery Disease (CAD)** diagnosis (`Cath`) and vessel-specific obstructive stenosis ($\ge 50\%$) across the three primary coronary arteries:
   - **LAD**: Left Anterior Descending Artery
   - **LCX**: Left Circumflex Artery
   - **RCA**: Right Coronary Artery
2. **Interactive 3D Coronary Anatomy**: Renders an interactive 3D digital twin of the human heart and coronary arterial tree derived from the open-source **BodyParts3D** anatomical repository (Foundational Model of Anatomy / FMA ontology), mapping predicted vessel stenosis probabilities directly onto anatomical branches via a dynamic risk colormap.
3. **Local Explainability (SHAP)**: Provides patient-level feature attributions powered by Lundberg TreeSHAP and LinearSHAP, decomposing predictions into clinical positive and negative risk contributors in exact model score (log-odds) margin space.
4. **Interactive Patient Simulator**: Enables clinicians to select representative patient archetypes or modify 54 clinical parameters in real time (e.g., blood pressure, ECG changes, lipid panel, ejection fraction) and instantly observe simulated shifts in vessel risk and 3D visual heatmaps.
5. **Production REST API**: Delivers a low-latency, stateless FastAPI backend with strict target leakage prevention, Pydantic data normalization, and uniform error envelopes.

## 2. Clinical Boundaries & Track A Medical Scope

### Medical Scope & Target Definitions
- **Dataset**: Extended Z-Alizadeh Sani cardiology dataset ($N = 303$ patients, 54 pre-catheterization clinical features).
- **Targets**:
  - `Cath`: Obstructive CAD confirmed by coronary catheterization (216 CAD / 87 Normal).
  - `LAD`: $\ge 50\%$ diameter stenosis in the LAD vessel (177 Stenotic / 126 Normal).
  - `LCX`: $\ge 50\%$ diameter stenosis in the LCX vessel (119 Stenotic / 184 Normal).
  - `RCA`: $\ge 50\%$ diameter stenosis in the RCA vessel (114 Stenotic / 189 Normal).

### Critical Medical & Spatial Boundary
The underlying tabular dataset contains clinical indicators (demographics, symptoms, ECG findings, labs, and echocardiographic parameters) and catheterization targets, but **does not contain 3D spatial lesion coordinates, voxel segmentations, or plaque length measurements**. 

Consequently, CoroVista adheres to strict clinical accuracy:
- **Visualized Values are Vessel-Level Probabilities**: Colormaps on the 3D coronary arteries reflect the **functional probability of obstructive stenosis** on that anatomical branch ($p \in [0.0, 1.0]$).
- **No False Plaque Geometry**: Predicted probabilities are mapped uniformly or via gradient flow across anatomical vascular territories; Regional Wall Motion Abnormalities (RWMA) and model scores are **never** fabricated as physical 3D lesion locations.

## 4. Multi-Target Machine Learning Benchmarks (Stage 2)

All pipelines were validated using **Repeated Stratified K-Fold Cross-Validation (5 Folds × 5 Repeats = 25 independent evaluation splits)** with strict feature isolation to guarantee zero data leakage.

| Target | Clinical Endpoint | Selected Model | Preprocessing | Calibration | ROC-AUC (Mean ± Std) | PR-AUC (Mean ± Std) | Balanced Accuracy | Brier Score | Decision Cutoff |
|---|---|---|---|---|---|---|---|---|---|
| **Cath** | Overall CAD Status | **XGBoost** | One-Hot / None | Sigmoid (Platt) | **0.910 ± 0.041** | **0.958 ± 0.021** | 0.843 ± 0.056 | **0.108** | 0.50 |
| **LAD** | Left Anterior Descending | **XGBoost** | One-Hot / None | Sigmoid (Platt) | **0.836 ± 0.049** | **0.878 ± 0.041** | 0.763 ± 0.056 | **0.165** | 0.50 |
| **LCX** | Left Circumflex | **RandomForest / XGBoost** | One-Hot / None | Uncalibrated | **0.724 ± 0.065** | **0.608 ± 0.086** | 0.662 ± 0.060 | **0.210** | 0.50 |
| **RCA** | Right Coronary Artery | **LogisticRegression** | One-Hot / Standard | Sigmoid (Platt) | **0.716 ± 0.060** | **0.613 ± 0.075** | 0.666 ± 0.048 | **0.225** | 0.38 |

### Key Machine Learning Findings:
1. **Target Leakage Safeguard**: Feature extraction strictly isolates target columns (`Cath`, `LAD`, `LCX`, `RCA`). If any target is detected in the input feature matrix, the pipeline raises an immediate `TargetLeakageError`.
2. **Probability Calibration**: Sigmoid Platt calibration significantly reduces probability calibration error (Brier score $< 0.11$ for Cath), providing reliable continuous risk estimates for driving the 3D colormaps.
3. **Threshold Calibration**: The optimal decision threshold for RCA is calibrated to **0.38** to optimize sensitivity and balanced accuracy for right coronary lesions.
4. **Ablation Studies**: Removing `Region RWMA` results in an acceptable minor drop ($-0.021$ for LAD, $-0.010$ for Cath), demonstrating robust predictive power across core clinical and laboratory features.

## 5. Explainability Engine & SHAP Architecture (Stage 3)

The explainability layer in [`src/corovista/explainability/`](file:///c:/Users/agnik/OneDrive/Desktop/CoroVista/src/corovista/explainability/) provides mathematically rigorous, local feature attribution:

### Exact Additivity in Model Score Margin Space
SHAP attributions are computed strictly in the **underlying model score / log-odds margin space**:
$$\sum_{j=1}^{M} \phi_j(x) + \phi_0 = f(x)$$
Where $\phi_0$ is the base expected value, $\phi_j$ is the attribution of feature $j$, and $f(x)$ is the uncalibrated model score.

### Technical Implementation:
- **Tree-Based Models (Cath, LAD, LCX)**: Uses native C++ Lundberg TreeSHAP via XGBoost booster `predict(pred_contribs=True)`.
- **Linear Models (RCA)**: Evaluated using `shap.LinearExplainer` over transformed, scaled feature matrices.
- **Calibrated Classifier Averaging**: For Platt-calibrated models (`CalibratedClassifierCV`), SHAP values are extracted across all underlying fold estimators and averaged.
- **Clinical Terminology Translation**: Automatically maps technical feature names to standard medical nomenclature:
  - `EF-TTE` $\to$ *Ejection Fraction (Echocardiography)*
  - `Tinversion` $\to$ *T-Wave Inversion (ECG)*
  - `Region RWMA` $\to$ *Regional Wall Motion Abnormality*
  - `TG` $\to$ *Triglycerides (mg/dL)*
  - `Typical Chest Pain` $\to$ *Typical Anginal Chest Pain*

For full mathematical documentation, see [`docs/explainability.md`](file:///c:/Users/agnik/OneDrive/Desktop/CoroVista/docs/explainability.md).

## 6. Backend REST API (Stage 4)

The backend is built with FastAPI and runs on port `8000`.

### Endpoints Overview

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/v1/health` | Service health status and model cache readiness verification |
| `GET` | `/api/v1/models` | Model registry, algorithms, calibrations, and decision thresholds |
| `GET` | `/api/v1/features` | Metadata for all 54 features (ranges, types, units, defaults) |
| `POST` | `/api/v1/predict` | Multi-target prediction (`cath`, `lad`, `lcx`, `rca`) with probabilities |
| `POST` | `/api/v1/explain` | Single-target SHAP waterfall attribution breakdown |
| `POST` | `/api/v1/analyze` | Comprehensive evaluation: 4 predictions + 4 SHAP explanations |

### Key API Features:
- **Authoritative Leakage Rejection**: Submitting any target column (`Cath`, `LAD`, `LCX`, `RCA`) triggers an instant `422 Unprocessable Content` response.
- **Standardized Error Envelope**: Consistent error structure with human-readable error messages and code identifiers:
  ```json
  {
    "error": {
      "code": "INVALID_INPUT",
      "message": "Target leakage detected: Ground-truth target columns ['Cath'] cannot be provided.",
      "details": []
    }
  }
  ```
- **Interactive Documentation**: Interactive Swagger UI at `http://localhost:8000/docs` and ReDoc at `http://localhost:8000/redoc`.

For full schema definitions and curl examples, see [`docs/api.md`](file:///c:/Users/agnik/OneDrive/Desktop/CoroVista/docs/api.md).

## 7. Interactive 3D Coronary Anatomy & Mesh Assets (Stage 5B)

CoroVista incorporates authentic anatomical geometries discovered and converted from the **BodyParts3D** open anatomical repository (FMA ontology).

### Anatomical Asset Discovery & Assembly
An exhaustive geometric audit of the 129 BodyParts3D OBJ assets established that all meshes share an **identical, pre-aligned millimeter coordinate frame** ($X \in [-35, 81]$, $Y \in [-177, -71]$, $Z \in [1175, 1293]$ mm). Multiple sequential trunk files were identified and merged into contiguous anatomical vessels:
- **LAD Trunk**: Joined `MM420` (Proximal) + `MM424` (Mid) + `MM425` (Distal) into a single 1,518-vertex arterial trunk from aortic root to cardiac apex.
- **RCA Trunk**: Joined `MM556` (Proximal) + `MM436` (Mid) + `MM439` (Distal) into a complete 1,607-vertex right coronary artery.
- **LCX Trunk**: Joined `MM426` (Proximal) + `MM635` (Distal) into an 8-segment trunk spanning the atrioventricular groove.
- **Structural Context**: Ascending Aorta (`MM506`), Aortic Bulb (`MM558`), Pulmonary Trunk (`MM607`), Interventricular Septum (`MM594`), and Left Ventricular Free Wall (`MM474`).

### Real-Time 3D Rendering Capabilities
Implemented in React Three Fiber (`@react-three/fiber`) and Three.js:
- **Dynamic Vascular Colormap**: Arterial branches transition smoothly according to predicted stenosis risk:
  - 🟢 **Low Risk ($p < 30\%$)**: Clinical Emerald (`#10b981`)
  - 🟡 **Moderate Risk ($30\% \le p < 50\%$)**: Clinical Amber (`#f59e0b`)
  - 🟠 **High Risk ($50\% \le p < 75\%$)**: Warning Orange (`#f97316`)
  - 🔴 **Critical Risk ($p \ge 75\%$)**: Acute Rose (`#ef4444`)
- **Pulsing Risk Glow**: Stenotic vessels ($\ge 50\%$) emit a subtle emissive pulsation to highlight at-risk vascular territories.
- **Interactive Raycasting**: Click or hover any coronary vessel to view its clinical label, stenosis probability, and binary prediction.
- **Anatomical Visibility Controls**: Toggle reference structures (Myocardium, Aorta, Pulmonary Trunk, Septum) or switch myocardium to semi-transparent glass for clear arterial viewing.
- **Fault-Tolerant Error Boundaries**: Gracefully catches WebGL context loss and presents a 2D coronary diagram fallback.

For complete geometric specifications, see [`docs/anatomy-assets.md`](file:///c:/Users/agnik/OneDrive/Desktop/CoroVista/docs/anatomy-assets.md).

## 8. Web Application & Clinical Dashboard (Stage 5A)

Built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**:

- **Pre-Loaded Clinical Archetypes**: Fast 1-click loading of representative patient scenarios:
  - *Typical CAD*: 62yo Male, Smoker, DM, Typical Chest Pain, ST depression, low EF $\to$ High Cath & LAD risk.
  - *Low-Risk Normal*: 48yo Female, non-smoker, normal ECG/Echo, normal labs $\to$ Low risk across all vessels.
  - *Isolated LAD Stenosis*: Patient with anterior ischemia and isolated LAD risk.
  - *Multivessel CAD*: Severe diffuse disease across LAD, LCX, and RCA.
- **Real-Time Patient Simulator**: Interactive drawer with sliders and toggles for clinical parameters (Age, Blood Pressure, Ejection Fraction, Chest Pain type, ECG findings, labs). Adjusting any slider dynamically re-evaluates backend models and updates the 3D heart model in real time.
- **Vessel Risk Cards**: Visual progress meters showing calibrated risk percentage, binary status badge, and target-specific threshold indicator.
- **SHAP Feature Attribution Cards**: Expandable positive/negative feature contribution waterfalls for any selected target vessel.

## 10. How to Run CoroVista Locally

### Prerequisites
- **Python**: Version 3.10 or 3.11
- **Node.js**: Version 18.x or 20.x+ (with `npm`)

---

### Step 1: Install Python Dependencies & Package
From the project root:
```bash
# Install package in editable mode with dependencies
pip install -e .
```

---

### Step 2: Start the FastAPI Backend
```bash
# Start backend on http://localhost:8000
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```
- API Base URL: `http://localhost:8000/api/v1`
- Interactive Swagger UI: `http://localhost:8000/docs`
- Health Check: `http://localhost:8000/api/v1/health`

---

### Step 3: Start the React Frontend Application
In a separate terminal:
```bash
cd frontend
npm install
npm run dev
```
- The application will be accessible at: `http://localhost:5173`

---

### Step 4: Run Automated Tests

CoroVista includes **87 automated tests** spanning ML integrity, API contracts, and React/Three.js components:

```bash

pytest

# 2. Run Frontend Vitest Suite (28 Tests)
cd frontend

```
